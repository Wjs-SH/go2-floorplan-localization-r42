    전역 위치는 E6/E7(의미 확인·재정합)이 연결되기 전까지 UNKNOWN 이다. 아래 후보는 모두 미검증 가설이다.

    E2/E3 TOP-K · 실제 다층 후보 (미검증 가설)

    score = E3 누적 기하 불일치(m, 낮을수록 좋음, 확률 아님) · e2 merit = 학생 metric_fit_v2 비용 · twoway = 학생 층 점수(높을수록 좋음) · 위치 m = 평면도 px / 추정 ppm (축척 미검증)

    층별·영역별 후보 분포 (모든 층을 같은 조건으로 탐색, 정답 층 미사용)

    ● ACTIVE · ○ SUSPENDED(보류, 계속 재평가) · 선 = 추정 진행 방향 · 굵은 테두리 = 현재 1위

    E3 · 이동 중 후보 갱신

    상위 후보 score 추이(이 화면을 연 뒤부터). 정지 중에는 새 키프레임이 없어 값이 유지된다.

    SEMANTIC NEED · 의미 관측 필요 (E4 → E5)

    대상 = 실제 의미지도(kci_handoff)의 방번호·시설. 팬틸트 명령은 보내지 않는다(조이스틱 회전은 운용자).
