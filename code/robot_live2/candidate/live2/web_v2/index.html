실험 준비

로봇이 어느 층·어느 구역인지 모르는 상태로 시작합니다. 구조만으로 구별되면 LiDAR로, 구별되지 않으면 표지판까지 사용해 위치를 스스로 결정합니다. 시작 위치(평가용)는 채점에만 쓰이며 위치추정 입력이 아닙니다.
하드웨어 사용 동의입니다. 위치 정보를 알고리즘에 주지 않으며, 실제 조준은 로봇이 표지판이 필요하다고 판단할 때만 합니다.




이 동의는 이번 실험에만 유효하며 [실험 종료] 때 자동으로 끝납니다. 서보 허용 범위·정지 확인·중복 실행 방지·HOME 처리는 그대로 적용됩니다.

진행 순서

1실험 시작

승인된 모듈을 순서대로 켭니다: FAST-LIO → 지도 축적 → 센서 → 기록 → SigLIP → E3/E4 → E2. 실패하면 이유를 보여 주고 자동 재시도하지 않습니다.

2정지 상태로 초기화 (10–20초)

“위치 입력 정상”이 뜰 때까지 로봇을 움직이지 마십시오 (FAST-LIO IMU 초기화).

3조이스틱으로 자유 주행

정해진 경로는 없습니다. 최근 60초 동안 2 m 이상 움직이면 전 층 위치 후보 탐색이 시작됩니다 (CPU, 약 7–8분/9개 층).

층·호실·정답 위치는 위치 추정에 전달되지 않습니다. 정답(GT)은 ‘실험 평가’에서 평가용으로만 기록합니다.
